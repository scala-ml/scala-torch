# scala-torch

Deep learning in Scala 3, targeting Java 25 and Python-free LLMs, training, and image generation.

Requires **Java 25, Scala 3.3.8 LTS, sbt 2.0.10**. Versions are pinned in the build.

Published Llama checkpoint inference now runs in Scala: standard config + single-file/indexed safetensors loading, differentiable model composition, persistent CPU KV cache, and greedy token-ID generation. The public tiny-random Llama matches 128000 independent Rust Candle logits with maximum absolute error `5.96e-8`; cached chunks also match that reference. This verifies architecture interoperability; the random checkpoint is not a useful language model. A native byte-level BPE tokenizer now matches the pinned SmolLM2 tokenizer reference. The trained SmolLM2-135M-Instruct model now generates text offline, matching independent Candle logits and greedy output.

Implemented: CPU tensors (Float32/Float64/Int64/Bool), checked shapes and views, slicing, broadcasting, Float32 add/reduction/matrix multiplication, and a numscala GEMM adapter. The FFM module includes host memory scopes, a real CUDA memory-copy probe, and a driver-level Float32 GEMM probe with owned stream/event completion.

First-order CPU Float32 autograd is available through `scalatorch.autograd.Variable`: shared graph gradients, broadcast reductions, GEMM, ReLU, reshape/transpose, detach and thread-local noGrad. A Python-free linear regression training test verifies loss reduction using automatic gradients.

Trainable `Parameter`, `Linear`, SGD and AdamW are available in `scalatorch.nn`. Case-class models use `derives Module` for nested parameter discovery, including Option/Vector fields and tied-weight deduplication. In-memory state dictionaries support strict, atomic loading.

Persistent training checkpoints now save weights, optimizer configuration, AdamW moments/counters, and a caller-supplied step. Restore validates the whole file before changing training state; deterministic save/reload/resume matches uninterrupted training exactly.

Transformer building blocks include trainable Embedding and RMSNorm modules plus differentiable SiLU. Embedding accepts Int64 token tensors with arbitrary leading shape and accumulates repeated-row gradients. RMSNorm normalizes the last axis using Double accumulations and Float32 output. A small token model trains these layers together in the integration suite.

Safetensors archives can now be indexed and read without Python: F16/BF16/F32→Float32, plus typed F64/I64/BOOL. Metadata is validated before payload loading, and tensors materialize individually. Interoperability is tested against a fixture generated by upstream Rust safetensors and loaded directly into a Scala layer.

Differentiable causal grouped-query attention and Llama-style RoPE are available on rank-4 `(batch, heads, tokens, width)` Variables. Attention supports query position offsets for decode chunks and a configurable score-workspace limit. Numerical gradient and masking tests cover these operations.

Not implemented yet: GPU transformer training, cuBLAS acceleration, broader tokenizer/config variants, or diffusion/NUI migration. Persistent GPU inference, CPU LoRA training and basic backend autodiff are described below. The small PTX GEMM kernel verifies correctness and FFM execution; it is not intended for model performance.

```scala
import scalatorch.*
import scalatorch.cpu.NumscalaBackend

val x = Tensor.fromFloats(Array(1f, 2f, 3f, 4f, 5f, 6f), Shape.from(Seq(2L, 3L)))
val gram = NumscalaBackend.matmul(x, x.transpose(0, 1))
assert(gram.toFloatArray.toSeq == Seq(14f, 32f, 32f, 77f))
```

`reshape` requires a contiguous layout; call `.contiguous` to copy a strided view first. Input and extracted arrays are copied. Operations currently use explicit CPU backends; no implicit device transfers or in-place public mutations.

```scala
import scalatorch.autograd.*

val x = Variable(Tensor.fromFloats(Array(3f), Shape.from(Seq.empty)))
val y = x * x + x
y.backward()
assert(x.grad.get.toFloatArray.toSeq == Seq(7f))
```

Raw Tensor operations do not record gradients; use Variable operations for differentiation. `backward` retains the immutable graph for reuse, accumulates gradients on leaves only, and requires `.zeroGrad()` to clear them. Use an explicit Tensor seed for nonscalar outputs. Gradients are first-order; parallel backward on shared leaves is unsupported. Variable reshape may copy a strided input, unlike strict raw Tensor reshape.

```scala
import scalatorch.nn.*

case class MLP(first: Linear, second: Linear) derives Module:
  def apply(x: Variable): Variable = second(first(x).relu())

val model = MLP(Linear.init(2, 8, seed = 41), Linear.init(8, 1, seed = 42))
val optimizer = AdamW(Module.parameters(model), learningRate = 0.03, weightDecay = 0.0)
// Per training batch: optimizer.zeroGrad(); loss.backward(); optimizer.step()
val snapshot = Module.stateDict(model)
Module.loadStateDict(model, snapshot)
```

Optimizer steps preserve gradients and reject nonfinite inputs before changing weights or Adam moments. Parameters keep their identity while replacing immutable values; backward rejects an older graph after a saved parameter changes. Explicit detach/noGrad results remain independent snapshots. The integration suite trains this MLP on XOR to MSE below `0.001`.

```scala
val path = java.nio.file.Path.of("training.stc")
Checkpoint.save(model, optimizer, path, step = 500)
val restoredStep = Checkpoint.load(model, optimizer, path)
```

Checkpoint restore requires matching model aliases/shapes/trainability and optimizer kind, parameter subset, and hyperparameters. Save at optimizer-step boundaries; gradients, RNG and data-loader state are not stored. This [training format](docs/research/checkpoint-format.md) is separate from the planned safetensors model loader.

```scala
val embedding = Embedding.init(vocabulary = 32, width = 8, seed = 1)
val norm = RMSNorm.init(width = 8)
val tokens = Tensor.fromLongs(Array(2L, 7L, 2L), Shape.from(Seq(3L)))
val hidden = norm(embedding(tokens)).silu() // shape (3, 8)
```

Embedding gradients are dense; padding-index and sparse-gradient options are not implemented. Module derivation treats Double fields such as RMSNorm epsilon as configuration, not parameters. Checkpoints store tensors, not model architecture/configuration: reconstruct matching layer settings before restoring.

```scala
import scalatorch.io.SafeTensors
import scala.util.Using

Using.resource(SafeTensors.open(java.nio.file.Path.of("weights.safetensors"))) { archive =>
  val weight: Tensor[Float] = archive.readFloat("weight")
}
```

Returned Tensors own their data and survive archive closure. The [reader evidence and limits](docs/research/safetensors-reader.md) document supported dtypes and configurable allocation limits. See [Llama model evidence and reproduction](docs/research/llama-model.md) for the separate published-model gate.

For attention, use `query.rope(positionStart).causalAttention(key.rope(0), value, queryStart = positionStart)` when keys cover positions starting at zero. Cached keys should already be rotated at their own positions. Grouped query heads must divide evenly into matching K/V heads. These are correctness-first CPU operations with no dropout, padding/custom masks, advanced RoPE scaling, or performance-parity claim; see [attention evidence](docs/research/attention-rope.md).

After downloading the pinned tiny checkpoint as documented in the [model guide](docs/research/llama-model.md), the Python-free CLI is:

```sh
sbt 'models / Compile / runMain scalatorch.models.LlamaRun .superpowers/models/tiny-llama 1,42,17,321 1'
```

It produces `1,42,17,321,16196`. Greedy inference uses a fresh KV cache by default; `useCache=false` retains full-prefix recomputation for comparison. Cache buffers and attention packing are CPU reference implementations; measured speedups or optimized-decoder parity are not claimed.

```scala
val cache = llama.newCache(batchSize = 1, capacity = 128)
try
  val prefill = cache.decode(Tensor.fromLongs(Array(1L,42L), Shape.from(Seq(1L,2L))))
  val next = cache.decode(Tensor.fromLongs(Array(17L), Shape.from(Seq(1L,1L))))
  assert(cache.position == 3)
finally cache.close()
```

Caches are inference-only, model-bound and budgeted (256MiB by default, configurable). Changed weights reject until reset; failures do not advance position. Returned logits own their data. See [KV-cache evidence](docs/research/kv-cache.md).

The target is concise Scala model authoring and Python-free real-model execution, rather than full PyTorch API compatibility.

The native tokenizer supports the inspected byte-level BPE pipeline (optional individual Digits), with explicit rejection of unsupported configurations:

```scala
val tokenizer = scalatorch.models.ByteBpeTokenizer.read(java.nio.file.Path.of("/model/tokenizer.json"))
val ids = tokenizer.encode("Hello, world!")
val text = tokenizer.decode(ids)
```

It inserts no BOS/EOS or chat template. SmolLM2 omits some byte symbols, so arbitrary input is not guaranteed to roundtrip. See [supported semantics and public-reference test](docs/research/byte-bpe-tokenizer.md).

Offline trained-model text generation (original SmolLM2-135M-Instruct `config.json`, `tokenizer.json`, `model.safetensors`):

```sh
sbt -batch ';set models / Compile / run / javaOptions += "-Xmx3g";models / Compile / runMain scalatorch.models.TextRun /absolute/path/to/smollm2-135m "What is the capital of France?" 16 --smollm-chat'
```

Verified output: `The capital of France is Paris.` Omit `--smollm-chat` for raw prompt mode. This flag explicitly chooses the pinned SmolLM2 template; arbitrary model chat templates are not interpreted. The CLI prints only the continuation. See [trained-model evidence and public test](docs/research/trained-text-generation.md).

Seeded sampling is available through the Scala API:

```scala
val policy = scalatorch.models.SamplingConfig(temperature=0.7,topK=20,topP=0.9,seed=42)
val generated = model.generateIds(promptIds,32,sampling=policy)
```

Temperature0 keeps the default greedy behavior. [Sampling semantics and tests](docs/research/token-sampling.md) cover temperature, top-k/top-p ordering, numerical boundaries and seed replay.

`LlamaModel.load(directory)` also accepts `model.safetensors.index.json` and its referenced shards. All shard headers and index assignments validate before model weights materialize. A directory containing both single-file and indexed weights is rejected as ambiguous. See [sharded-checkpoint validation and independent reference](docs/research/sharded-safetensors.md).

The [NUI migration ledger](docs/research/nui-migration-audit.md) tracks the remaining Python removal work against47 worker requests and117 standard plugins at a pinned source revision. These features are inventoried, not yet migrated.

Causal language-model training now composes `model.forward(input).crossEntropy(targets)` with AdamW. Classes are on the final axis; targets are Long IDs with matching batch/time dimensions. A synthetic Llama next-token test reduces loss from2.1746 to0.000660. See [loss semantics and training example](docs/research/cross-entropy.md).

[CPU LoRA adapters](docs/research/lora.md) now support selected Llama attention/MLP projections with frozen base weights and adapter-only optimizer parameters. A pinned SmolLM2 last-layer test trains 7,680 parameters and reduces synthetic-token loss from20.86 to4.61. `LoRACheckpoint.save/load` persists adapter weights and optimizer state with exact base/configuration binding; tiny-Llama and pretrained SmolLM2 tests verify exact continuation.

The [persistent CUDA storage layer](docs/research/native-backends.md#persistent-device-storage) supports explicit Float32 upload/download and chained GEMM with intermediates kept on device. Scoped ownership, per-session allocation budgets and individual buffer release are implemented. General Tensor/autograd dispatch remains pending; prepared model GPU execution is described below.

[`FloatBackend[T]`](docs/research/float-backends.md) provides shared CPU/CUDA inference operations: GEMM, equal-shape add/multiply, scalar multiplication, SiLU and last-axis RMSNorm, with explicit transfer and release. The same generic gated MLP/residual computation is tested on both backends. Prepared transformer GPU execution is described below.

Backend embedding and layout operations now gather validated Long token IDs, reshape CUDA tensors with shared allocation ownership, and transpose arbitrary axis pairs into packed device outputs. Activations and embedding tables stay on the GPU; integer metadata transfers are explicit implementation work covered by the allocation budget.

Backend rotary positions and causal grouped-query attention now run on CPU or CUDA, including offset queries and bounded score workspace. CPU forward results match existing autograd; real-GPU tests cover numerical agreement and causal masking. Prepared full-model GPU integration is now verified below.

[Prepared Llama inference](docs/research/backend-llama.md) now runs complete models with resident CPU or CUDA weights, including LoRA factors. The native CUDA CLI generates **The capital of France is Paris.** from pinned SmolLM2 weights, and all196608 independent Candle reference logits pass the existing tolerance. GPU training remains pending; resident KV caching is described below.

[Resident backend KV caches](docs/research/backend-kv-cache.md) now make cached CPU/CUDA generation the default. Device K/V buffers stay at fixed capacity, cached SmolLM2 logits match Candle, and rejected decodes leave the committed position unchanged.

[Scoped backend autodiff](docs/research/backend-autograd.md) now differentiates matrix/layout, basic arithmetic, SiLU and RMSNorm operations on CPU or CUDA. A resident GPU training test learns `y=2x+1` in 100 steps, reducing loss from9.0 to1.21e-13. A gated transformer MLP also trains with CPU gradient/update parity over20steps, reducing loss0.0951→0.0224. Both restore their allocation baseline after every step. Embedding/rotary/attention backward and backend optimizer/checkpoint integration remain open. Enable the separate real-GPU autograd gate with:
