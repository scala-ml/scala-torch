# scala-torch 0.1.0 release candidate

Status: local release preparation; **not published to Maven Central**.

Requires Java 25. Built with Scala 3.3.8 LTS and sbt 2.0.10. The first release groups verified library components; it does not mark completion of the Python-free Stable Diffusion NUI migration.

Included:
- Typed CPU tensors, checked layouts/views, reference operations and numscala matrix multiplication.
- First-order CPU autodiff, derived parameter traversal, neural network layers, SGD/AdamW and deterministic checkpoints.
- Safetensors single/sharded loading and native byte-level BPE support for the tested Llama path.
- Published Llama/SmolLM2 inference, token generation, LoRA/full training and exact training continuation.
- Java 25 FFM CUDA driver execution with resident Llama inference/training and owned resource lifetimes.
- Differentiable diffusion components, published conditional U-Net loading, CLIP text conditioning and tested CLIP-to-U-Net integration.

Important limitations:
- No full PyTorch compatibility, automatic backend migration or production-performance CUDA GEMM/cuBLAS claim.
- Diffusion runs on CPU. Prompt tokenization/weighting, VAE, schedulers and complete image generation/NUI remain unfinished.
- The tiny public diffusion checkpoints verify interoperability, not useful image quality.
- CUDA is verified on the available Linux GTX 1650 SUPER; Windows and other device/driver combinations need separate evidence.
- Java 25 Scala runtime dependencies still produce an Unsafe deprecation warning in parts of the test suite.
- The early 0.x API can evolve; versionScheme is early-semver.

After the packaging changes, all 312 tests passed with public-model and actual-CUDA gates enabled. A source-independent consumer compiled against the seven staged jars and passed CPU autodiff and public CLIP-to-U-Net execution. Artifact checks and the remaining publication requirements are recorded in [PUBLISHING.md](../PUBLISHING.md).

The release remains pending license/source metadata, signing credentials, actual Central publication and public artifact-resolution verification. No successful publication is claimed by the version string alone.
