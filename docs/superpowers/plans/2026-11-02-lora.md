# LoRA implementation plan

Implement frozen-base low-rank adaptation using existing CPU autograd. The user has approved the library implementation; execute inline.

1. Add `LowRankAdapter(a, b, alpha)` and optional `Linear.lora`. Compute `x Aᵀ Bᵀ * alpha/rank`, initialize A randomly and B to zero, validate dimensions and finite representable scale. Provide a freezing attachment helper without mutating the source layer. Verify analytical gradients, initialization, optimization isolation, and validation.
2. Attach adapters to selected Llama projection modules/layers. Freeze all base parameters while retaining tied aliases. Enforce allocation limits before attachment. Expose adapter-only parameters and ensure cache invalidation follows adapter updates.
3. Train a tiny Llama and a last-layer adapter on the pinned SmolLM2 model. Verify loss reduction and bitwise unchanged base weights. These are execution checks, not quality benchmarks.
4. Save adapter-only optimizer checkpoints in an atomic bundle binding config, alpha, target paths and base Float32 weights by fingerprint. Validate bounded contents before restore. Verify exact continuation and reject mismatched bases or corrupted bundles without mutation.
5. Run all module suites, public model gates and CUDA checks; request read-only review and address findings.

Each step is a separately reviewable checkpoint. No PEFT compatibility, dropout, adapter merging or GPU training is claimed. The existing full NUI migration remains open.

Persistence implementation uses a fixed 48-byte versioned envelope around the existing STCKPT01 payload. It reuses the validated optimizer serializer and avoids introducing archive parsing. Base/configuration binding is recomputed at each save/load. Caller reconstruction is explicit; automatic model download/config recreation is outside this training checkpoint API.
