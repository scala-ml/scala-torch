# Persistent Llama KV Cache Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Decode incrementally without recomputing prior token projections, with verified prefill/decode equivalence.

**Architecture:** Model-bound CPU inference cache owns preallocated Float32 K/V buffers per layer, batch, KV head and capacity. Appends write only the new tail and expose private strided prefix views to attention. RoPE rotates new keys/queries at the committed offset; old keys are not rotated again. A step commits position only after all layers/head succeed. Failure leaves the old prefix length intact; tails are overwritten on retry. Parameter identity snapshots invalidate stale caches. Reset rebinds weights and discards prefix; close releases buffer references.

**Tech Stack:** Scala 3.3.8, sbt 2.0.10, Java 25, existing models.

**Spec:** Approved design `docs/superpowers/specs/2026-11-02-scala-torch-design.md`, M3 KV/prefill/decode gate.

## Global Constraints

- Inference-only, always noGrad; differentiable full forward remains separate.
- Batch and capacity positive, capacity <= config context; default cache budget 256MiB, configurable.
- Shape/ID/context/output/score limits checked before committing state.
- No concurrent model parameter updates with decode; decode/reset/close on one cache serialize.
- No sliding windows, eviction, GPU cache, or zero-copy/performance parity claim. Attention currently packs private prefix views internally.

## Review Focus

- Batch/head capacity strides and multi-token chunk offsets must match full-prefix logits.
- Failed decode must not advance position or expose tail writes.
- Parameter updates must reject until reset, including frozen parameters.
- Budget arithmetic must not overflow before allocation.
- Close/reset must not leak mutable buffer views through returned tensors.
