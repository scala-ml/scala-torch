# SDXL U-Net Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, task by task. No subagents are authorized for this session.

**Goal:** Run SDXL U-Net predictions with explicit text/size conditioning on CPU and CUDA, preserving SD1.5 behavior. This is one part of the full NUI Python-removal goal, not its completion criterion.

**Architecture:** Extend the existing U-Net graph and loader with per-stage heads/depth and optional text-time addition. Map linear spatial projections to mathematically equivalent 1x1 convolution storage after validating the original 2D archive shape. Reuse current CUDA operators, resource scoping and weight offload.

**Tech Stack:** Scala3.3.8, existing Tensor/autograd/modules, safetensors, Java25 FFM CUDA; optional PyTorch/Diffusers CPU oracle only.

**Spec:** NUI migration requirements in `docs/research/nui-migration-audit.md`; public [SDXL base U-Net config](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/raw/main/unet/config.json); pinned tiny SDXL revision `fa06b5c3d6d45fabd978486616c6dae068519e85`, source `hf-internal-testing/tiny-stable-diffusion-xl-pipe`. Local configs/weights are in `.superpowers/models/tiny-sdxl-pipe` with source-metadata.json.

## Global constraints

- Runtime must not invoke Python; optional `scripts/reference_sdxl.py` creates local safetensors and independent fixture tensors after upstream SHA verification.
- Preserve existing SD1.5 public defaults and strict unknown-weight/config rejection.
- CPU and CUDA must implement identical conditioning semantics; no silent omission of pooled text or size conditions.
- Keep NUI changes on `feat/scala-torch-native-engine`. No main merge/push.
- Normal SDXL has more than the current1B U-Net parameter limit: expose/use an explicit sufficient budget at the eventual worker boundary; do not silently remove allocation guards.

## Review focus

- Reversed up-block stage indices must select the corresponding down-stage heads/depth (Task1).
- Linear archive projection rank must be validated before reshaping; no accepting arbitrary extra singleton axes (Task1).
- Missing, nonfinite, wrong-batch or wrong-width added conditioning must reject before inference (Task2).
- GPU failure/cancellation must retain caller inputs and release additions/temporary weights (Task3).
- Text-time embeddings must distinguish original size, crop and target size rather than accidentally reusing a constant (Tasks2/3).
